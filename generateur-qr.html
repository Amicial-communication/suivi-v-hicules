📊 Générateur CSV pour InDesign

Amicial - Fusion de données avec QR Codes

📋 Comment utiliser ce générateur ?

  1. Ouvrez votre fichier Excel avec la liste des véhicules
  2. Sélectionnez et copiez les 4 colonnes : Marque, Modèle, Plaque, Agence
  3. Collez dans le champ ci-dessous
  4. Cliquez sur "Générer le CSV"
  5. Téléchargez le fichier CSV
  6. Importez-le dans InDesign (Fenêtre → Utilitaires → Fusion de données)
💡 Astuce : Copiez directement depuis Excel. Les tabulations, virgules ou points-virgules sont détectés automatiquement dans le champ ci-dessus.
⚠️ Important : L'ordre des colonnes doit être Marque, Modèle, Plaque, puis Agence.
📐 Le CSV généré utilise la virgule comme séparateur (format standard requis par InDesign).

✅ Aperçu du CSV généré

📐 Utilisation dans InDesign

  • Importer : Fenêtre → Utilitaires → Fusion de données → Sélectionner la source de données → ce CSV
  • Vérifier : dans le panneau Fusion de données, le champ #QRCODE doit afficher une icône QR code (pas une icône "T" de texte). Si ce n'est pas le cas, le fichier n'est pas bien reconnu.
  • QR Code : dessinez un cadre vide à l'emplacement voulu, puis glissez le champ #QRCODE depuis le panneau directement sur ce cadre (ne pas utiliser Objet → Générer le code QR pour ce champ)
  • Texte : insérez les champs <<MARQUE>>, <<MODELE>>, <<PLAQUE D'IMMATRICULATION>>, <<AGENCE>> en les glissant aussi depuis le panneau
  • Créer : Fusion de données → Créer un document fusionné → Tous les enregistrements
